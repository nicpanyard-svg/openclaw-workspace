PROGRAM OVERVIEW
RapidQuote builds customer proposals for equipment, recurring connectivity,
services, and major projects. It supports purchase and equipment lease quotes,
pricing review, terms, customer proposal previews, PDF output, workbook exports,
and internal order summaries.

Stack: Next.js 16.2.1 App Router, React 19.2.4, TypeScript, Tailwind CSS 4.
PDF tooling includes browser-rendered HTML, pdf-lib, PDF.js, and Puppeteer.
Workbook tooling includes ExcelJS, XLSX, and formula calculation libraries.
Quote and proposal persistence includes browser storage; do not assume records
on one browser automatically appear in another browser or machine.

MAIN CODE MAP (paths relative to app root)
- app/components/quote-preview.tsx: main quote editor and save/export actions.
- app/components/customer-output-settings.tsx: final commercial questions.
- app/lib/quote-record.ts: quote data types.
- app/lib/quote-template.ts: blank quote defaults.
- app/lib/proposal-state.ts and proposal-store.ts: quote/proposal persistence.
- app/lib/major-project.ts: major-project pricing and proposal projection.
- app/lib/proposal-customer-content.ts: customer-facing wording and warnings.
- app/components/proposal-document.tsx: current customer HTML proposal.
- app/api/proposal-pdf/route.tsx: PDF export endpoint using HTML rendering.
- app/lib/proposal-spec-pdf-assembly.ts: combines proposal and attachments.
- app/lib/terms-packages.ts: package defaults, including legacy Net 30 wording.
- app/lib/order-processing.ts: internal order summary and readiness checks.
- app/lib/processing-requirements.ts: required intake details.

USER REQUIREMENTS / DECISIONS

At the end of quote creation, ask:
1. How long is the agreement? Common suggestions: 12, 24, 36 months; custom allowed.
2. What are the payment terms? Net 30, Net 60, prepaid, or custom.
3. When does billing start? Activation, installation, or a specific date/custom text.
4. Should equipment ship activated? Yes/No, only when included equipment may ship.
Other details should be collapsed by default. Lease and overage fields should
appear only where applicable. Answers must drive proposal wording.
